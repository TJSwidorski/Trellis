# Evolution

`proposals/` holds change proposals Trellis wrote about itself, with evidence
attached. Advisory proposals are classified as eligible for auto-apply once
regression is green, but no apply mechanism exists yet — every proposal, advisory
or load-bearing, waits for you to read it and act. Protected paths cannot be
proposed at all — see `references/EVOLUTION.md` and `MISSION.md`.

Commit this directory. The proposal history is how you notice the system drifting
toward greener runs rather than better software.
