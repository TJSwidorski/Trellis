# Evolution

`proposals/` holds change proposals Trellis wrote about itself, with evidence
attached. Advisory proposals auto-apply once `trellis regression` is green;
load-bearing ones wait for you to merge them. Protected paths cannot be proposed
at all — see `references/EVOLUTION.md` and `MISSION.md`.

Commit this directory. The proposal history is how you notice the system drifting
toward greener runs rather than better software.
